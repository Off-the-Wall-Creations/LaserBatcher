LaserBatcher guide

Batch SVG copies onto a laser sheet

Use a regular arrangement of copies when you want the same SVG design repeated across a sheet. LaserBatcher keeps the source canvas size as the footprint of each copy.

1. Open your SVG

Choose Open SVG in the toolbar. The main canvas initially displays Source. An ordinary SVG opens in Create batch; a recognized LaserBatcher export defaults to Edit metadata. Select Create batch explicitly if you want to repeat a previous export as a new source.

If import reports a size or format problem, follow the SVG preparation guide. Resolve blocking Issues before rendering.

2. Set the sheet and copy count

Enter Width and Height in inches. Horizontal margin reserves space at the left and right; Vertical margin reserves space at the top and bottom. Spacing is the gap between source canvases. Set Copies yourself, or use Fill to use the available capacity.

For example, a 2 × 1.5 inch source on an 8 × 5 inch sheet with 0.25 inch margins and 0.125 inch spacing fits three columns and two rows: six copies. This uses the whole source canvas, including any blank area; it does not crop or automatically nest individual shapes.

On a narrow window, open Sheet to edit these settings and Apply them. Use Program for optional part, order, batch and yield fields.

3. Review operation mapping

Open Mapping and check included, ignored and unresolved counts. Give unresolved production elements an operation, or choose Ignore to omit them. Group assignments apply to descendants unless a closer explicit assignment overrides them. At least one production element must be included.

Choose Within each copy or Across the sheet for operation order. Read the mapping guide for the difference and for clone dependencies.

4. Render and inspect the batch

Press ▶ Render (Render batch). This generates a preview; it never starts a laser. The canvas switches to Batch. Use Fit, zoom and pan to inspect it, and switch back to Source for comparison. Clear preview returns to Source while retaining your inputs.

5. Download and check in your laser software

Download SVG becomes available after a valid render. Changes to batch settings or assignments require another render. The download uses your program fields and total yield in its filename and leaves the uploaded original untouched.

Open the result in your laser software and verify scale, retained settings and actual operation order there. LaserBatcher has no connection to the machine. You can add a whole-job Estimated Runtime after reviewing your setup, or re-upload the export to add it later.
