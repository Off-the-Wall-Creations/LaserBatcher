LaserBatcher guide

Map, ignore and order SVG operations

Operation Mapping connects the artwork in an SVG to Engrave, Score, Interior Cut or Exterior Cut. Ignore omits selected production geometry from the batch.

Assign a group, then refine its children

The nearest explicit assignment wins. Assigning a group applies to its descendants unless a closer group or element has its own explicit assignment. Choose From source / parent to remove an explicit assignment and return to source or inherited mapping.

Canonical operation labels can initialize mapping. Suggestions and ambiguous labels need review: a generic Cut label, or a raw Glowforge type="cut", is not enough to decide Interior Cut versus Exterior Cut or to infer Score.

Expand and collapse groups to navigate the list. Collapsed groups still show production and unresolved descendant counts. Assignments and totals include every production element, even those in closed groups. Collapsing changes only the view.

Use Ignore with child overrides

Ignore excludes production occurrences from rendered batches and downloads. For example, Ignore a construction-guides group, then assign one child to Score if that mark should remain. An explicit child operation overrides the parent's Ignore assignment.

Ignored elements remain visible in the mapping list so you can restore them. They count as ignored rather than unresolved. Rendering requires at least one included production element; an all-ignored job displays “Include at least one production element.”

Ignore changes invalidate the rendered batch and clear an entered runtime estimate. They do not resize the source canvas or change packing capacity, source yield or copy count. Licensing, hidden content, semantic metadata and unrelated definitions retain their preservation rules.

Inspect an element without changing production styling

Click a thumbnail for an enlarged preview inside the mapping panel. Enhanced mode uses contrasting colors and non-scaling strokes; Original shows the original styling. The main canvas remains on its current Source or Batch view, and inspection colors never enter an export.

Understand clone dependencies

A clone can reference artwork that is ignored as a production occurrence. If the clone remains included, LaserBatcher retains its required source subtree as a non-rendering definition and remaps IDs and references for each copy. Assignments do not propagate through clone references.

That retained definition supports the included clone; it does not reintroduce the ignored original as visible production geometry. Unsupported dependency transformations block export with an actionable error. Simplify the dependency in your SVG editor before trying again.

Choose operation order

The category sequence is Engrave → Score → Interior Cut → Exterior Cut.

  • Within each copy applies that sequence to one copy, then proceeds to the next.
  • Across the sheet groups each category across all copies before proceeding to the next category.

Supported Glowforge step definitions are regenerated for included artwork while retaining power, speed, passes, focus and unknown setting attributes. Empty steps are omitted, and changes to native order produce warnings. Review the separate raw settings and readable report values in Glowforge settings when available.

These choices control exported structure. They do not guarantee that laser software will honor that order. Verify the imported result and machine settings in the application you use to run the laser.
